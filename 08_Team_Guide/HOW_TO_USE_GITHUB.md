# How to Use GitHub - Team Guide

## 1. First Time Setup

1. Install GitHub Desktop.
2. Sign in using your GitHub account.
3. Open the project repository:

   https://github.com/menamielad/Frequency-Meter

4. In GitHub Desktop, select:
   File > Clone Repository
5. Choose the Frequency-Meter repository.
6. Select a local folder and click Clone.

## 2. Before Starting Work

Always download the latest changes:

1. Open GitHub Desktop.
2. Select the Frequency-Meter repository.
3. Click Fetch origin.
4. If updates are available, click Pull origin.

## 3. Working on Files

1. Open the project folder in VS Code.
2. Navigate to the section assigned to you.
3. Edit or add your files.
4. Save your changes.

Do not edit files assigned to another team member without coordination.

## 4. Saving Changes

1. Open GitHub Desktop.
2. Review the changed files.
3. Write a short summary in the Summary field.
4. Click Commit to main.
5. Click Push origin.

## 5. Important Rules

- Always Fetch and Pull before starting work.
- Do not delete another member's files.
- Use clear file and folder names.
- Do not upload temporary files or unnecessary downloads.
- Do not upload passwords or private information.
- Record actual test results only.
- Coordinate before editing the same file.
